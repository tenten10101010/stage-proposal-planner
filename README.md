# Stage Proposal Planner

A reusable Codex skill for turning scattered project materials, meeting notes, transcripts, screenshots, and rough ideas into clear stage proposals, reports, and presentation storylines.

## What it helps with

- Clarify the audience, objective, decision, and final artifact.
- Separate confirmed facts, strategic judgment, inference, and unverified claims.
- Build a coherent proposal structure from fragmented materials.
- Define the role of each project module and the value exchanged between them.
- Plan documents, reports, one-page briefs, partner proposals, and PPT storylines.
- Maintain visual consistency without repeating one rigid slide template.

## Install

Copy the `stage-proposal-planner` folder into:

```text
~/.codex/skills/
```

## Use

Example prompt:

```text
Use $stage-proposal-planner to turn these materials into an external partner proposal, then recommend whether the final output should be a document, report, or PPT.
```
